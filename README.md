

**About the Project**

This repository contains the synopsis and implementation details of a low-cost RADAR System developed using Arduino and ultrasonic sensors. The project focuses on object detection and visualization using simple and affordable hardware components.


**2. Problem Statement**

Traditional radar systems are expensive and require complex infrastructure. This project aims to design and develop a low-cost, Arduino-based RADAR system capable of detecting objects such as fighter jets, aircraft, and other obstacles using ultrasonic sensors.

**3. Objectives and Scope**


**Objectives**

* To design an affordable RADAR system using Arduino

* To detect objects within a predefined range

* To display object position and distance visually

**Scope**

* Suitable for educational and learning purposes

* Can be used for basic surveillance and object detection

* Can be integrated into larger tracking or monitoring systems

**4. Methodology**

<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/d89cddbd-7cdd-44a6-ba2e-cd957406adb6" />

The system uses an Arduino UNO R3 SMD microcontroller to control an HC-SR04 ultrasonic sensor mounted on a servo motor (SG90).
The servo rotates the sensor to scan the surroundings. Distance data is collected and processed by Arduino and displayed graphically using Processing software.

**5. Hardware and Software Requirements**


**Hardware**

1. Arduino UNO R3 SMD (with USB cable)

2. HC-SR04 Ultrasonic Sensor Module

3. Tower Pro SG90 Servo Motor (180°)

4. Jumper Cables

5. MB102 400-point Solderless Breadboard


**Software**

1. Arduino IDE

2. Processing (for graphical visualization)
